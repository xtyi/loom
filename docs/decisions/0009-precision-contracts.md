# 决策 0009 精度策略离线，运行时执行数值契约

- 状态：已接受，具体 schema 待原型验证
- 时间：2026-10-23

## 决定

Kernel Harness 选择 FP32/FP16 等混合方案，决定转换边界、固定权重转换、量化校准与质量预算。runtime 校验类型和契约匹配，执行已编译 KernelUnit，不按算子名称隐式决定精度。

Cast、Quantize、Dequantize 和动态量化参数计算可在运行期执行，通过普通节点或声明了相应数值契约的融合实现表达。离线制定策略不等于所有数值转换必须离线计算。

存储 dtype 与内部计算/累加精度分开描述；量化按需记录 scale、zero point、轴/分组、舍入和饱和。运行时能检查声明的一致性，不能从声明证明二进制行为，必须有独立验证。

## 验证

- 实现正确性：与符合目标数值契约的独立参考比较。
- 模型质量：完整 plan 与原始模型基线及任务指标比较。
- FP64：仅在适用时用于误差分析，不是所有模型的唯一真值。

比较规则由应用预算及独立验证流程确定，记录参考版本与样本来源，kernel 生成 Agent 不得修改。低精度和高精度参考的观测差不能直接作为普适误差下界。

## 首版范围

先支持显式 FP32/FP16 方案与 Cast 用例；自动混合精度搜索、BF16 与 INT8/FP8 按需求扩展。生产默认不跑 golden 对比。见 [Kernel Harness](../08-kernel-harness.md) 和 [校验服务](../09-runtime-services.md)。
